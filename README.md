# Intelligent Pesticide Sprinkler System

Smart pesticide sprinkling system using Raspberry Pi and ESP32 for plant disease detection, severity analysis, and optimized pesticide dosage.

Conventional pesticide spraying often requires farmers to manually carry spraying equipment through agricultural fields. This can be physically demanding and may become difficult in narrow crop rows, uneven terrain, or areas where a wheeled spraying system cannot maneuver effectively.

The mechanical design was developed by considering actual field conditions, crop-row spacing, available operating space, maneuverability, and ease of operation. The system consists of a compact remotely controlled rover for spraying between crop rows, along with a portable backpack-based spraying option for locations where the rover cannot physically access the field.
